# SSH 中文管理菜单

菜单是已有命令的交互入口，不是网页面板，不新增管理监听端口。
本轮仅本地整合；未在 VPS 安装系统级 `snellctl` 快捷命令，尚待菜单实机验收。
不因独立命令曾实测通过，就认定菜单和未验证的实际升级已经通过。

## 进入方式

在已核验的源码目录和交互终端中运行：

```bash
python3 -E -s -B -m snellctl menu
```

普通模式只提供查询、预览及明确确认后显示客户端配置的入口。
Surge 配置包含密钥，不要分享该输出。浏览菜单不读取凭据、不联网，也不自动执行健康检查。
需要实验变更入口时单独使用：

```bash
python3 -E -s -B -m snellctl menu --experimental
```

该参数仅显示入口，不授予某项变更许可。选中操作后仍由原命令检查现场、终端和归属，
分别征求所需确认；确认沿用 `[y/n]`，默认取消，仅 ASCII y/Y 继续。
不要把这些命令当作当前公开提交已经更新的通知；发布前应继续使用已确认的版本。

## 菜单范围

主菜单 1 至 14 的编号不变，包括环境检查、部署预览、受限安装/接续、记录、
客户端配置、密钥/端口/Token/域名管理及旧域名资源核查/清理。
变更项目只在实验模式显示，手动输入隐藏编号也不能调用。

菜单 15「组件维护」：

| 编号 | 操作 | 普通模式可用 |
| --- | --- | --- |
| 1 | 本机组件盘点，不联网、不升级 | 是 |
| 2 | 原更新任务状态，不恢复 | 是 |
| 3 | 联网检查更新方案，写独立缓存 | 否 |
| 4 | 下载并保存升级包审查材料，不安装 | 否 |
| 5 | 实际 Debian 包更新，可能停机 | 否 |
| 6 | 原更新任务受限恢复，不重新安装 | 否 |

实际升级和受限恢复仍未完成实机验收，菜单明确提示这一限制。
没有更新时正常返回子菜单，不自动安装或强制制造候选，也不会跳到实际升级。
不提供 Snell/ShadowTLS 程序自动升级，不接受菜单输入作为任意命令执行。

菜单 16「卸载与重装」：

| 编号 | 操作 | 普通模式可用 |
| --- | --- | --- |
| 1 | 只读核查卸载范围 | 是 |
| 2 | 只读核查成功卸载后的重装条件 | 是 |
| 3 | 卸载完整受管节点 | 否 |
| 4 | 成功卸载后的受控重装 | 否 |

这里不是第三方节点接管、通用故障恢复或整机重置入口。
卸载仍须分别确认资源归属、备用 SSH、最终服务状态以及停机和不可撤销删除。
重装保留历史、重新生成节点密钥；不以菜单选择代替核查。
特殊历史现场的 Token/清理恢复命令仍保留为独立命令，不混入通用菜单。

## 退出和失败

- 子菜单输入 0 返回主菜单，主菜单输入 0 退出。
- 成功的独立操作返回所在菜单；是否完成外部验收仍以该操作的报告为准。
- 独立操作返回非零状态时，整个菜单退出并保留失败或取消状态，不再读取下一项选择。
- EOF、Ctrl+C 或未预期异常退出菜单，不显示原始异常，不自动重试、回退或重启。
- 已进入可能写入的操作后，不声称主机未改变；是否写入及恢复方式应查对应记录。

菜单不是断线保护。SSH 断开、断电或强制终止后仍须核查具体阶段，不能重新打开菜单就重复执行。
变更操作保留原有秘密输入、独立确认、锁、状态检查和失败记录约束。

本地测试覆盖普通/实验两种模式、所有新增路由、隐藏编号拒绝、返回导航、
无更新后不安装、取消/失败停止、异常脱敏，以及伪终端中的真实命令启动和退出。
原有节点管理及确认测试继续保留；这些不代表 Debian 实机菜单或真实包升级已通过。

已本地实现独立的 [快捷入口首次安装](command-install.md)：核对当前源码、已有命令冲突、
受限安装路径及归属，不引用临时目录，不改变当前节点的卸载/重装范围，尚待批量发布及实机验证。
菜单本身不会自动安装、下载、更新或覆盖系统级管理命令；安装必须单独确认。
