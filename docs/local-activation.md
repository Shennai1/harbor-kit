# 本机激活与续期演练

本批新增 `activation.py` 与 `tlsprobe.py`，接在内部软件包/证书准备之后。
已接入[实验安装向导](install-wizard.md)，**不要在现有 VPS 上试装或手动调用内部接口。**
这些模块能够写系统配置和启动服务，但本批没有连接 VPS、CF 或 ACME。

## 阶段边界

首轮仅支持 Debian 13 / amd64、新机、单节点 `main`。
内部方法接收已完成准备的对象、配置参数及下载文件，不自行猜测目标主机或域名。
下载材料在落盘前重新核对固定版本摘要、压缩格式和 ELF，不能拿暂存收据代替校验。
摘要仍是手工验证基线，不是上游签名。

本机激活期间三个组件均仅监听 `127.0.0.1`：Snell 后端、Nginx TLS 后端及 ShadowTLS 入口。
入口使用未来选择的端口，但尚未监听公网，不依赖 UFW 恰好阻断它。
成功返回 `local-active-public-entry-not-enabled`，不等于节点已可对外使用。

下一阶段才会切换公网监听、增量放行 UFW、登记开机启动并启用自动续期。
对应内部模块现已补充，见 [公网启用与自动续期](public-enablement.md)，仍待 Debian 实机联调。
此前只读菜单与计划预览仍描述最终期望的公网配置，不代表本机试运行已公开。

## 配置与保护

激活前核对正式证书准备记录、已安装包版本、启动保护和端口空闲。
根据实际 `nginx -v` 选择模板，而非采用计划预览的默认版本。
只接受没有额外站点、模块加载或服务覆盖的新安装状态。

基础 Nginx 配置与 dpkg 记录的 conffile 摘要比较；这是本地修改检测，不是独立来源认证。
`nginx -T` 加载文件集合必须符合本轮方案。已有配置改动或额外文件会停止接管。
移除默认站点时，只移除指向软件包默认站点、且身份未变的启用链接；默认站点文件本身保留。

生成两份独立随机密码，保存在运行所需的 `0600` 配置中。
程序版本目录、两个节点服务、Nginx 站点和部署钩子均只新建，不覆盖。
状态记录只保存绑定摘要、文件身份、模式和摘要，没有第二份秘密配置。
这些摘要不是匿名化，也不应发布状态目录。

配置及服务语法检查后才移除本工具创建的 Nginx mask，并按顺序启动三个服务。
本阶段保留 Certbot service/timer 的 mask 和临时包启动策略，不登记服务开机启动。
重复调用会复核文件及运行状态，不轮换密钥、不重新签证书、不重复启动。

## 运行验收

- 检查三个服务运行、退出状态为零、未自动重启，无额外覆盖，主进程与监听一致。
- 检查 Snell 的 TCP/UDP、本机 TLS 与入口 TCP 都只监听回环；发现目标端口公网监听就失败。
- 对 Nginx 和 ShadowTLS 入口分别建立真实本机 TLS 1.3 连接。
- 验证受信证书链及域名，比较运行中叶证书与磁盘叶证书，确认 HTTP 404。
- TLS 1.2/1.3 分别测试错误和缺失 SNI，必须收到 `unrecognized_name` 警报。
  连接拒绝、超时、客户端自身证书校验失败都不能冒充服务端拒绝成功。

正向连接始终启用证书验证。仅负向握手检查关闭客户端证书校验，确保拒绝确实来自服务端。
检查固定连接 `127.0.0.1`，不解析公网域名、不使用代理；这不验证 DNS、公网路由、云安全组或实际代理认证。
TLS 超时限制针对每次网络操作，不是整个部署流程的总时间保证。

## 续期演练

本机激活通过后，可在明确确认下执行同一 lineage 的 staging dry-run。
显式禁用自动遍历目录钩子，只调用身份已验证的本节点部署钩子，避免执行其他脚本。
运行环境继续隔离，原始输出只在内部检查，不写进状态或显示给用户。

不能仅凭 Certbot 返回零判定成功：还必须看到部署钩子的成功标记，
随后再次检查服务、监听、TLS 及运行证书与磁盘证书一致。
已核对 Certbot 4.0.0 会缩进显示钩子输出，检查允许行首尾空白，但不放宽成功标记内容。

演练成功返回 `renewal-tested-timer-still-blocked`。
**自动续期定时器仍未启用，不能把此阶段当成完成部署后长期运行的状态。**
dry-run 不替换正式证书，也不等于真实证书轮换已验收。
后续还需对定时任务的实际运行环境、保存的续期参数、开机恢复做专门联调。

## 中断处理

开始写入前记录激活意图。启动或检查失败后，尽力停止本轮尝试启动的服务；
停止命令失败会明确要求人工核查，不宣称服务已停。
保留配置、密钥和意图记录，不自动卸载软件、重写凭据或重做签发。
重复调用遇到未完成意图时停止；当前没有自动恢复这批系统变更的入口。

进程被强制杀死或机器断电时，清理代码不保证执行，可能留下部分已启动的回环服务。
文件系统写入和外部服务操作不是原子事务。不得靠删除记录强行重跑。
不支持与其他管理员或部署工具并发改动同一配置；受信的 root 环境是前提。

## 验证情况

本机激活批次完成时套件 214 项通过，本批新增 35 项；最新总数见项目 README。这里覆盖配置冲突、启动失败、中断、
重复操作、未知监听、续期钩子未执行和重载后健康检查失败。
新增真实本机 TLS 测试，使用临时生成且仅供测试的证书及短暂回环监听；运行结束后清理。
测试证书不是提供给用户节点的自签证书方案。

APT、systemd、Nginx、Snell、ShadowTLS 和 ACME 的集成执行仍由模拟器响应。
真实 TLS 测试证明探测器行为，不证明 Debian 组件组合已自动部署成功。
未触碰现有 VPS，没有升级组件、公开端口或创建 GitHub 仓库。
