# Surge 客户端配置显示

本功能只读取**由本工具完成公网启用的单节点 main**，不修改服务器、客户端或防火墙。
它不迁移第三方脚本节点，也不自动认领此前手工搭建的测试节点，即使文件路径相同。

在目标部署主机的 Linux root 交互终端中运行：

```bash
python3 -m snellctl client
```

也可以打开普通中文菜单，选择 `5. 显示 Surge 配置（含密钥，需确认）`。
这项操作不需要安装开关 `--experimental`，但每次都需要单独确认显示秘密。

## 确认与输出

1. 输入这台 VPS 的公网 IPv4，不含端口。暂不接受域名、IPv6、内网或文档示例地址。
2. 阅读敏感信息提示，输入“显示”继续；直接回车或其他输入取消，不读取节点密钥。
3. 程序核对部署完成记录和当前磁盘配置，只显示一行可放入 Surge `[Proxy]` 的节点声明。

连接地址是用户输入的 IPv4；公网端口、两项密钥及证书域名均从现有配置提取。
证书域名自动填写为 `shadow-tls-sni`，不会把 IPv4 当作 SNI，也不会把 Snell 或 Nginx 的本机端口当作公网入口。
无需手工输入长密钥。终端视觉折行不是换行，复制后在 Surge 文本配置中确认它仍是一条声明。

现有 `[Proxy]` 区段只增加节点行，不覆盖整个配置文件或重复创建区段。
默认节点名为 `snellctl-main`；若已有同名节点，只更改新行等号左侧的名称，保留原节点及规则。
程序不会修改 Surge 的规则、策略组、订阅或系统代理设置。

输出明确指定 Snell `version=5`、ShadowTLS `shadow-tls-version=3`，并使用对应的独立密钥和 SNI。
字段依据 [Surge Snell 说明](https://manual.nssurge.com/policies/snell.html)
和 [ShadowTLS 说明](https://manual.nssurge.com/policies/tls.html)，不自动切换到其他协议大版本。

首版沿用手工测试的 `block-quic=on`，不添加 `skip-cert-verify`、固定证书指纹、UDP 端口或额外混淆选项。
`block-quic=on` 阻断 QUIC，但不等于关闭所有 UDP；只支持 QUIC 的应用可能因此无法使用。
该组合的普通 UDP、QUIC Proxy Mode 和 IPv6 尚未验收，不应因 Snell 协议自身支持某项能力就视为已通过。
参见 [Surge 通用参数](https://manual.nssurge.com/policies/parameters.html#block-quic)
及 [UDP Relay](https://manual.nssurge.com/policies/udp.html)。

## 读取边界

读取过程取得本工具的操作锁，检查完成记录、文件身份、权限和内容摘要，再核对配置间的关系及支持的模板。
读取固定路径，不跟随记录中插入的任意路径，不接受已替换的同名文件、符号链接、硬链接或非普通文件。
发现额外服务覆盖、未知字段、错误监听范围或不匹配的域名记录时停止，不猜测或修复。

解析器只适用于当前生成的模板，不是通用 Nginx/第三方脚本解析器。
Nginx 新旧 HTTP/2 语法均可识别，这不意味着新增了 Debian 12 实机支持，也不是实际软件版本或补丁检查。
配置被手动修改后，即使你确信修改正确，也不会自动更新归属记录以绕过检查。

不读取 Cloudflare Token、证书私钥、账户密钥或服务日志；不运行系统命令、不联网、不查询外部 IP 服务。
不新建导出文件，不调用剪贴板工具，不重新生成密钥，不记录输入的连接 IP。
如果存在未确认完成的密钥更换意图，拒绝导出；应保留记录并先核查现场，不使用旧版工具绕过。
成功完成单项更换后，本入口读取更新后的当前配置，而不是初次安装时的历史密钥。
本机服务可能已停止、证书可能已过期或 IP 可能填错，**导出成功不证明当前健康或外部可用**。
导出也不会验证用户输入的 IP 是否属于当前 VPS。

## 隐私与错误

输出含真实明文节点密钥，不属于脱敏诊断，不能发送到对话或公开分享。
终端回滚缓冲、屏幕共享、录屏、SSH 会话审计、手动复制后的剪贴板历史可能保留输出。
交互终端限制不能阻止这些记录，也不能保证内存安全擦除。

没有 `--json`、`--output`、`--yes`、Token 参数或通过参数指定根目录的入口。
输入、输出和错误输出必须都是交互终端；不接受管道和文件重定向。
所有错误提示固定，不回显原始配置、密钥、IP 输入或异常文本。
若显示途中中断，只能提示可能已显示部分秘密，不能承诺没有泄露。

返回 `0` 表示配置显示完成，`130` 表示取消/中断，`2` 表示非交互终端被拒绝，`1` 表示校验或显示失败。
这些状态都不会触发自动重装、清理、续期或重启。
尚未完成公网启用时先查看 `install-status`；不要为导出而删除意图记录或重新安装。

新安装的验证顺序见 [新机实测清单](new-host-acceptance.md)。
