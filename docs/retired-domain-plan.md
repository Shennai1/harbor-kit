# 旧域名清理预检查

`retired-domain-plan` 或普通菜单 13，只核对用户明确输入的一个旧完整域名。
适用范围仍为本工具完整管理的 Debian 13 / amd64 / IPv4 TCP 单节点 main。
它不是清理器，没有 `--apply`、自动确认或删除入口；有限范围及现用本机检查已有一轮用户实测通过反馈。

```bash
python3 -E -s -B -m snellctl retired-domain-plan
```

在已校验源码目录的 root SSH 交互终端执行。不接收域名、Token 或目录命令行参数。
输入已经替换掉的真实完整小写域名，不是现用域名，也不是 `domain-inventory` 的 `other-1` 编号。
先在本机显示输入的目标，再用 `[y/n]` 确认仅核查；空输入或除 y/Y 外的回答取消。
确认预检查不等于确认删除，不需要重新提供任何 Token 或节点密钥。

## 本轮检查

1. 对现有部署加协作锁，拒绝未完成的域名、凭据、端口或密钥操作。目标等于现用域名立即停止。
2. 复用既有现用节点检查：文件摘要/模板、实际 Nginx 配置来源、证书、服务、回环 TLS、
   UFW 与 SSH 记录、定时器和 Certbot 空闲状态。不改变它们，不中止正在运行的 Certbot。
3. 重跑有限资源盘点，不能有未知条目、超限、异常权限或未解析的续期引用。
4. 核对目标 live 链接、archive 目录各代文件、Certbot 续期文件中的五条固定资源路径。
   不接受外部路径、跨证书组路径、意外文件、缺项、符号链接替代或多重硬链接。
   用 OpenSSL 读取目标公开证书，要求 SAN 只有输入的那个域名；不要求旧证书尚未到期，
   不验证旧私钥内容与证书的对应关系，也不把 SAN 视作文件归属证明。
5. 从原始 DNS 演练域名摘要或目标域名曾成功更换的脱敏报告中寻找历史线索。
   **早期版本没有保存完整的旧资源归属清单，因此历史线索永远不能证明当前文件都可自动删除。**
6. 要求目标凭据路径与现用路径不同，且只被目标的续期配置引用；拒绝共享凭据或未知外部路径。
   对固定 Nginx 站点、模块和 Certbot 钩子目录要求符合当前受管范围，额外配置必须先人工审查。
7. 再次检查现用健康、部署指纹、资源盘点以及目标路径元数据变化；仍不保存或执行计划。

只在声明的范围内检查引用。其他应用、容器、定时任务、未覆盖的服务配置仍需管理员核对，
不能把没查到解释为全机无人使用。独立凭据文件也不证明 Cloudflare 上的 Token 没有在其他机器使用。

## 隐私和副作用

- 只在本机提示中显示用户输入的目标域名；最后 JSON 不含域名、IP、凭据内容、秘密指纹或具体旧文件名。
- 现用节点配置、凭据和私钥会在既有健康检查中用于内存校验，不输出秘密。
  旧 Token 和旧私钥只检查元数据；旧公开证书由 OpenSSL 读取。
- 不执行 Certbot，不联系 Cloudflare/CA，不申请或续签证书，不变更 DNS，不安装快捷入口。
- 不暂停定时器，不重载/重启服务，不操作软件包，不修改 UFW/SSH，不写新的计划、意图或归属记录。
  系统命令使用临时输出，本机 HTTPS 检查可能产生常规服务日志，不能宣称整个文件系统绝无写入。
- 这是非原子快照，协作锁不能阻止外部管理员或 Certbot 修改现场。真正清理前必须再核对。

## 结果

`scope-checked-confirmation-required` 表示这次有限范围和现用本机健康检查通过，**不是删除授权**。
`historical_file_ownership_proven=false` 与 `cleanup_authorized=false` 是预期的诚实边界，不能手改为 true。
下一步仍需管理员确认资源归属与不存在其他用途、独立删除确认，以及执行前重新核查。

`blocked-preserve-all` 给出脱敏 `failure_phase` 和 `reason`。停止后资源保持不由本命令修改；
不要为了通过检查删除标记、关闭防火墙、移除其他站点或暂停续期。分享最后 JSON 即可。

本轮候选审查范围是旧证书组、其续期配置及其独立本地凭据文件。
现用节点/证书、软件包、ACME 账户、历史日志、DNS 和 Cloudflare 令牌撤销均排除在外。

后续清理使用独立的实验入口及两次确认，见 [旧域名资源清理](retired-domain-cleanup.md)。
使用 Certbot 的证书删除接口，而不是手动删除其目录；删除前须移除实际引用。
删除本地证书也不等同吊销证书，参见 [Certbot 安全删除说明](https://eff-certbot.readthedocs.io/en/stable/using.html#deleting-certificates)。
本版路径检查依据 [Certbot 4.0 存储实现](https://github.com/certbot/certbot/blob/v4.0.0/certbot/certbot/_internal/storage.py)，
不代表兼容所有其他 Certbot 版本或自定义配置。
