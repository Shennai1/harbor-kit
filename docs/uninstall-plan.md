# 受管节点卸载范围预检查

`uninstall-plan` 只读入口没有删除开关或快捷入口。
该预检查已有 Debian 13 / amd64 受管 main 的用户实机正常路径反馈，不扩展为所有环境通过。
另有[独立卸载执行器](uninstall.md)的实验实现，必须分别核查和确认，尚未实机验收。
通过只表示有限范围核对完成，不表示允许停止现用节点或已经恢复成新机。

## 首版范围

仅接受 Debian 13 / amd64 上本工具完整管理、当前正常运行的单节点 `main`。
从受限配置和当前记录中读取域名、两项密钥、端口及证书/凭据路径，不要求重新输入，
不使用测试机的实际域名或端口作为固定目标。程序版本路径来自工具现有支持目录，
未来版本选择功能仍需另行实现，不能把任意目录名当成已支持的程序版本。

- 核对受管文件身份、内容摘要、模板、程序和当前配置绑定。
- 核对服务、回环后端、公网入口、本机 TLS、证书材料、续期配置与定时器。
- 核对现有 UFW 和 SSH 监听，匹配唯一的受管 IPv4 TCP 入口规则及其内核规则。
- 有界核对节点、程序、Nginx、证书、凭据及续期钩子目录；额外资源阻止本轮范围通过。
- 复查部署及已观察文件的元数据，发现并发变化即停止，不修复、不重试。

不接受手工或第三方节点、不完整安装、配置被外部修改、待核查变更标记、
正在运行的 Certbot 或已暂停的续期。不能靠补写记录、清除意图或修改权限让检查通过。
这不是服务故障恢复工具，也不是全机依赖分析。

## 只读交互

取得经审核的含此入口的固定版本后，在目标主机项目目录的交互终端使用：

```bash
python3 -m snellctl uninstall-plan
```

仅有一次“只核查、全部保留”的 `[y/n]` 确认，默认取消。
没有 `--apply`、`--yes`、`--experimental`、`--root`、域名或 Token 参数；不加入菜单编号。
不停止节点、不暂停续期、不修改 UFW、不执行 Certbot、不下载或删除文件。
不访问 Cloudflare 或 CA；会执行本机 TLS 检查，可能产生常规服务日志。
会读取现用受管秘密作内存核验，原始内容、指纹、域名和完整路径不会进入报告。
既有协作锁不阻止外部 root 操作，请勿同时运行其他管理操作或 Certbot。

报告只包含范围计数、检查阶段和脱敏状态，不保存新的状态文件或报告。
退出码 `0` / `uninstall-scope-checked-no-changes` 不是卸载许可；
`uninstall_authorized`、`host_changes_attempted` 始终为 `false`。
本版的 `uninstall_implemented=true` 仅说明另有执行器代码，不表示已实机验收或获得卸载许可；
此前只有预检查的版本此字段为 `false`。
核查失败返回 `1` 并保留全部资源；非交互调用返回 `2`，主动取消返回 `130`。

## 后续卸载设计边界

下表描述执行器的设计范围，当前只读入口不执行这些动作，不能作为可执行删除清单。

| 范围 | 后续处理原则 |
| --- | --- |
| main 两项节点配置及两个专用服务 | 独立停机确认后才能处理；先核对内容/身份、实际运行和启动关系 |
| 受管 IPv4 TCP 放行 | 只考虑有记录且唯一匹配的一条；保留 SSH、UFW 和全部其他规则，不重置防火墙 |
| main 的 Nginx 站点、重载钩子和续期覆盖 | 与证书和服务生命周期一起处理；不能先删证书让仍加载的配置失效 |
| 当前证书组和独立本机 CF 凭据 | 要求用户确认独占用途；先解除引用，再用 Certbot 删除明确证书组，不删整个证书目录 |
| 两个版本化程序 | 即使内容匹配也不证明没有外部使用者，仍需无其他消费者确认 |
| Nginx / Certbot 的运行及开机状态 | 必须明确卸载后的状态；不能删除续期覆盖后无条件恢复可能处理其他证书的通用定时任务 |
| 软件包、供应商服务文件、内核和软件源 | 本轮设计保留；若以后移除，单独审查依赖，不执行自动依赖清理 |
| ACME 账户、历史日志和受限管理记录 | 保留，不以“恢复新机”为理由一并递归删除；残留清理另行审查 |
| Cloudflare Token、DNS、证书吊销 | 不作云端操作；本机文件删除不等同撤销或吊销 |

正式卸载前仍需确认独立 SSH 新连接和恢复控制台，明确现用节点会停止工作，
重新核查归属和共享引用，然后单独授权不可撤销删除。当前健康检查不能代替这些授权。
独立本地执行候选采用停用 Nginx/续期、保留软件包和历史的最终状态；中断保留标记，不自动恢复，
不能借用旧域名清理的成功结果宣称整机卸载已经安全可用。

证书引用先于删除的顺序依据 [Certbot 官方删除说明](https://eff-certbot.readthedocs.io/en/stable/using.html#safely-deleting-certificates)。
服务的禁用和停止不是同一状态，后续执行器必须分别验证；
参见 [systemctl 257 文档](https://www.freedesktop.org/software/systemd/man/257/systemctl.html#disable%20UNIT%E2%80%A6)。

## 验证边界

本地测试使用临时模拟部署、systemd/UFW 输出和模拟本机 TLS，不操作真实 VPS。
重点覆盖多余/共享资源、路径和权限异常、状态变化、失败输出脱敏、命令只读门禁、
已更换域名/端口的配置，以及正常检查不改文件、规则、服务或历史。
真实主机只读预检查正常路径已收到用户通过反馈；卸载执行和卸载后重装尚未验收。
