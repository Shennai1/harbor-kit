# 开发路线图

这是通用公开路线图，不包含服务器、账户凭据或私人操作记录。
仓库为开发源码，尚无正式发布版；不能把单元测试通过当作目标系统部署成功。

## 已有能力

- 只读环境盘点、参数化计划和有限新机预检查。
- 官方固定版本下载校验，独立沙盒内的文件写入和恢复演练。
- 软件包、DNS-01 证书、本机服务和公网启用的实验交互向导。
- 中文 SSH 菜单、独立确认、隐藏 Token 输入及脱敏错误提示。
- 受控客户端配置显示、历史阶段查询、清理前只读盘点。
- 严格限于本机及续期演练通过、尚未开始公网开放阶段的交互接续；已完成节点拒绝执行。
- 实验性单项密钥更换：独立更换 Snell PSK 或 ShadowTLS 密码，失败保留记录并阻止继续；正常路径已有用户实测通过反馈。
- 实验性 IPv4 TCP 公网端口更换：限定 UFW 增删、保留 SSH 和后端端口；双向更换及正常重启已有用户通过反馈，[实测范围及限制](port-change.md#已取得的实测证据)。
- 实验性 CF Token 更换：候选及固定路径分别演练，成功后恢复续期；权限修正后的受限接续已取得实机通过反馈，[范围及中断风险](token-change.md)。
- 实验性域名更换：读取当前参数，独立新证书和区域凭据，成功后更新 SNI 和续期目标；正常流程及正常重启已有用户实测反馈，[边界及验收要求](domain-change.md)。
- 域名资源只读盘点：匿名列出现用/其他证书组与凭据引用，有限范围已有实机通过反馈，不作删除授权。
- 旧域名清理预检查：明确选择目标，核对现用本机健康、历史线索和共享引用；不执行删除，有限范围已有用户实测通过反馈。
- 实验性单个旧域名清理：两次确认、重新核查后删除旧证书组及独立本机凭据，保护现用节点；尚待实机验收，不是卸载器。
- 确认提示统一为默认取消的 `[y/n]`，仅 y/Y 继续，保留各项独立授权及操作目标说明；待实机验证新提示。

手工基线覆盖 Debian 13 / amd64 / IPv4 TCP 的连接、实际应用、模拟续期与开机恢复。
实验安装取得一轮用户实测反馈：断线后经人工核查及一次性命令接续，客户端和正常重启通过。
随后两项密钥分别更换、新客户端配置可用及正常重启后的服务恢复也取得用户通过反馈。
该结果不替代密钥管理菜单路由、失败恢复、断电或其他机器的验收，见[实测范围](key-rotation.md#已取得的实测证据)。
公网端口的低/高双向更换、权限调整及换回后的正常重启恢复也已取得用户通过反馈；
不将其扩展为端口管理菜单路由、故障恢复、旧端口外部拒绝或长期稳定性已通过。
完整向导及新菜单接续入口仍待独立复测；普通 UDP、QUIC Proxy Mode、IPv6、Debian 12 和 ARM64 尚未验收。

## 下一阶段

1. 从固定提交取得新代码，在获授权的独立测试环境复测完整向导和菜单接续，保留目前正常运行的节点。
2. 验证取消接续、断线及已完成节点拒绝重试；不为测试而删除阶段记录或模拟生产故障。
3. 需要复用机器时另行盘点并确认清理范围，保护 SSH/UFW，不认领第三方节点；按 [实测清单](new-host-acceptance.md) 记录结果。
4. 补充真实到期续签和更广中断场景验证；已有正常重启通过不代表断电、所有故障恢复或长期稳定性通过。
5. 保留已通过的密钥、端口、Token 受限接续及跨区域域名更换基线；完成旧资源清理实测，再处理按归属卸载和失败恢复。不提前安装快捷入口。
6. 分组件实现补丁更新、版本选择及必要回退；再适配其他系统/架构和 IPv6。
7. 增加 CI、发行校验材料及经过验证的远程入口，然后决定正式版本范围。

本地测试不修改真实 VPS；部署、续期和防火墙控制在测试中使用模拟器。
只有下载/本机 TLS/子进程/文件系统等对应测试使用真实实现，不混称整机集成验收。
仓库公布只代表代码可获取，不改变现有实验风险和独立授权要求。

## 发布范围

公开源树只包含审核过的代码、测试及通用文档，不包含第三方可执行文件、
API Token、私钥、客户端配置、日志、真实服务器域名/IP、私人历史笔记或完整聊天记录。
`tools/public_source.py` 使用固定文件清单导出，并进行基础敏感模式检查。
该检查不是完整秘密扫描或人工审查的替代品。新增公开文件必须显式加入清单。

仓库公开不等同自动授予开源许可证；许可证仍待独立选择。
