# 卸载后重装预检查

`reinstall-plan` 只读检查本工具已经成功卸载的 Debian 13 / amd64 单节点 main。
它不是重装执行器，也不能恢复中断或部分卸载。当前仅完成本地测试，尚未实机验收。
不要在不包含本功能的旧源码中运行此命令；固定版本交付仍需单独确认。

```bash
python3 -E -s -B -m snellctl reinstall-plan
```

仅接受交互终端，默认 n 的 `[y/n]` 确认只读核查。
不输入新域名、端口、Token 或路径，不提供 `--apply`、`--yes`、`--experimental` 等执行开关。
不安装快捷命令，不改变现有菜单。命令退出码 0 表示本次有限范围检查通过，不表示允许重装。

## 核查范围

- 使用已有协作锁，不新建、删除或替换状态目录和锁文件。
- 核对卸载完成记录、独立成功报告、证书删除尝试记录与历史部署记录的一致性。
- 活动卸载、清理或更换标记必须不存在。初次安装遗留的阶段记录仍属历史，不重新执行。
- 从历史记录取得原 SSH/公网端口；不假设任何用户域名、SSH 端口或旧入口值。
- 原节点配置、专用服务、程序、证书、独立凭据、Nginx 站点、部署钩子和续期覆盖应已移除。
  只接受支持版本的已知空目录布局，额外节点、程序版本、凭据、站点、证书或钩子均保留并阻止通过。
- 两个节点服务应不存在；Nginx 和 Certbot 定时器保持停用，Certbot 服务空闲，实际加载的供应商单元无覆盖。
- 已安装依赖状态和软件包审计应正常，Nginx 基础配置及供应商服务文件与本地包记录一致。
- 复用现有只读 SSH/UFW 检查，核对旧入口规则未重现、旧公网端口和已知组件没有监听。
- 再次读取服务、监听、规则与软件包状态，复查已观察的文件元数据；变化则停止，不自动接受新快照。

不读取已删除的秘密，也不读取 ACME 账户内容、日志或剩余陌生文件内容。
账户目录只检查元数据；不判断账户有效性，不将其认定为可直接复用的授权。
报告不包含域名、端口、完整路径、密钥、Token 或内容指纹；不保存新的计划或持久报告。
系统查询使用适配器的临时输出文件；读取可能更新文件访问时间，不承诺磁盘取证层面的零变化。

## 结果含义

通过时：

```json
{
  "result": "reinstall-scope-checked-no-changes",
  "current_state": "uninstalled-local-checks-passed",
  "reinstall_ready": false,
  "reinstall_implemented": false,
  "reinstall_authorized": false,
  "host_changes_attempted": false,
  "report_saved": false
}
```

未通过时返回 `blocked-preserve-all`，只输出阶段和固定原因，不打印原始异常或命令输出。
不自动清理文件、修复权限、解除 mask、启停服务或重置防火墙。
即使检查失败，本入口也没有启动重装，不要通过删记录来绕过。

这不是全机安全审计或引用搜索。未检查云安全组、全部内核规则、容器和外部任务；
SSH 服务及放行规则不证明独立 SSH 新连接成功。协作锁无法阻止不遵守协议的外部 root 操作。
软件包摘要只反映本地内容一致性，不证明软件源可信或安全补丁最新。
本入口不执行 Nginx 测试、Certbot、APT 更新、网络请求、证书验证或申请。
旧后端端口可能已不可从保留记录还原，因此不宣称检查了所有旧端口或新部署端口的可用性。

## 下一阶段边界

真正重装仍须单独实现和审核：在保留历史与锁连续性的前提下隔离新一轮记录，处理中断和部分写入，
重新核对软件源及依赖，重新选择域名、端口和区域凭据，生成全新两组节点密钥，
独立确认 CA 条款、签发及公网开放，并完成客户端和重启验收。
保留的 ACME 账户、软件包、空目录和历史不应被当作“全新 VPS”。
原 `install` 新机保护检查没有放宽，不能在本次预检查通过后直接重跑它。
